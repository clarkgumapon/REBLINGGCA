# Niel's Fitness Gym Management System

A modern, full-stack gym management system built with Next.js 13, featuring a responsive UI and comprehensive functionality for members, staff, and administrators.

## Features

### Member Features
- **Member Dashboard**
  - View membership status and payment history
  - Track workout progress
  - Schedule training sessions
  - Access workout history
  - Update profile information

### Staff Features
- **Staff Dashboard**
  - Real-time analytics and statistics
  - Member check-in/check-out management
  - Class schedule management
  - Member progress tracking
  - Daily attendance monitoring

### Admin Features
- **Admin Dashboard**
  - Comprehensive business analytics
  - Revenue tracking and reporting
  - Member management
  - Staff management
  - Payment verification
  - Membership plan management

### General Features
- **Authentication & Authorization**
  - Secure login system
  - Role-based access control
  - Password recovery

- **Membership Management**
  - Multiple membership plans
  - Automated payment tracking
  - Membership status monitoring
  - Payment history

- **User Interface**
  - Modern, responsive design
  - Dark/light mode support
  - Mobile-friendly layout
  - Interactive charts and graphs

## Technology Stack

- **Frontend**
  - Next.js 13 (App Router)
  - React 18
  - TypeScript
  - Tailwind CSS
  - Shadcn UI Components
  - Recharts for data visualization

- **State Management**
  - React Hooks
  - Local Storage (for demo purposes)

## Getting Started

### Prerequisites
- Node.js 16.8 or later
- npm or yarn package manager

### Installation

1. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
